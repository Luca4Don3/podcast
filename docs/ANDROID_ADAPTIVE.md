# Android 多屏适配

应用实时读取当前 Activity 的实际窗口、密度和系统安全区（系统栏、显示切口、软键盘），由 Jetpack WindowManager 提供折叠铰链的边界、遮挡、分隔与半开状态。折叠展开、旋转、分屏和窗口大小变化后会重新计算；不按厂商或型号猜测。

| 场景 | 适配方式 |
|---|---|
| 窄长直屏、折叠外屏 | 保留单栏和底部导航；窄窗仅显示当前导航项的文字，其他项仍有无障碍名称。 |
| 普通直屏 | 单栏内容、底部导航与迷你播放器。 |
| 宽窗、展开后无分隔的平板 | 根据可用宽高切换侧栏；播放器按父容器实测宽度决定是否双列，内容区限制最大阅读宽度。 |
| 竖铰链 | 避开铰链，在两侧分布内容和播放器；RTL 界面交换主次侧。 |
| 水平铰链、桌面姿态 | 内容留在上方、播放控制留在下方。多铰链或无法分区时回退到最大的连续安全区。 |
| 刘海、挖孔、胶囊 | 避开系统上报的切口与安全区。厂商不通过窗口 Insets 公布的临时悬浮胶囊不是可识别的硬件缺口。 |

大字、窄窗、短横窗下，展开播放器支持纵向滚动；文字、时间和播放控件根据可用空间回流，播放按钮保留至少 48dp 触控目标。连续改变窗口时保留导航状态，不主动重启播放。

## 验收建议

- 分别在普通直屏、窄长外屏、宽屏和折叠展开上观察导航。播放时折叠／展开或转动，确认当前页和播放状态保留。
- 在模拟显示刘海、居中挖孔、双切口的设备上检查登录、导航和展开播放器，确认系统栏、切口与键盘不遮住主要操作。
- 大字体下检查文件音源、设置、播放器及放大后的触控区；折叠设备要分别检查竖铰链、桌面姿态、外屏及不同厂商系统。
- JVM 单测验证窗口和铰链几何策略，不能替代设备厂商的 WindowManager 扩展行为或视觉验收。
