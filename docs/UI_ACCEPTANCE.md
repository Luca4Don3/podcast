# Android 1.3.0 验收矩阵

本轮目标是改进常用流程，而不是承诺所有机型已经覆盖。继续使用 C/C++ 音源扫描和 C++ 后端；界面、媒体和系统权限仍使用 Android 平台组件。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 登录与服务器设置 | 不填服务器地址打开应用；设置地址、键盘提交；再切换地址 | 未配置时引导到可选服务器设置，不发登录请求；换服务器清空内存中的密码和邀请码 |
| 窄屏及大字体 | 320dp 手机、系统字体 200%；登录、导入、设置、播放器逐页检查 | 主操作可滚动到达，文字不覆盖输入框，按钮不挤出屏幕 |
| 横屏及宽屏 | 在至少 600dp 宽且 320dp 高的可用内容区切换四个入口，缩小分屏后再恢复 | 宽窗用侧栏、窄窗用底栏，切换窗口与页签时保留所在页；节目详情返回正确 |
| 资料库与错误恢复 | 空库进入 RSS 导入或电台；填无效及有效地址；有缓存内容时断网刷新 | 可找到下一步；失败可重试并保留原输入或已加载内容 |
| 播放器 | 播放慢源、错误源和本机测试源；缓冲时暂停，失败后重试；拖动进度和取消拖动 | 状态明确；暂停、重试可用，不被迟到的续播响应覆盖进度 |
| 无障碍及系统交互 | 深色、TalkBack、手势导航和三键导航；横屏打开播放详情、倍速和睡眠定时菜单 | 读出关键操作与状态，内容避开系统栏，控制可操作 |
| 账户恢复 | 模拟续期 503／无网络、明确 401、过期访问令牌后退出、离线退出、同一账号重登 | 暂时失败不清会话，仅确认为当前会话失效时清理；本机退出和服务端撤销结果分别报告 |
| 首播与锁屏 | Android 8、12、13、14/15：首次播放失效源、快速暂停、马上锁屏，分别允许和拒绝通知 | 不崩溃；正常源可续播，检查前台服务和媒体通知 |

重点仍需真机验证：旧系统、厂商后台限制、TalkBack 实际朗读、新系统标题栏及大字体。媒体前台服务冷启动时，慢源或失败可能影响服务晋升时序；本轮未改服务启动策略，也未确认在设备上复现。设置页和播放页的倍速、跳转时长即时同步仍待改。

## 本轮实测范围

- Android：精简构建成功，60 项 JVM 测试通过，含导航断点、播放切换、认证失败和并发会话回归。APK 验证通过签名、API 24/35、四 ABI 及 16 KiB 对齐。
- 后端：C++ CTest 通过，现有 C++ 和 Go 交付件的 8 组内容范围冒烟检查通过，未修改或部署后端。
- 未通过运行环境验收：无已连接真机，Android 15 模拟器在 ADB 离线后退出，未能执行屏幕截图、界面交互或锁屏播放测试。
