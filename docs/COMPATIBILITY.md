# 兼容性说明

本项目在「客户端 Android 版本、设备形态、语言区域、弱网离线、服务端运行环境、老数据升级」六个维度上做了兼容处理。

## 1. Android 版本

| 版本 | API | 关键变化 | 本项目处理 |
| --- | --- | --- | --- |
| Android 7.0–7.1 | 24–25 | 最低支持版本 | 启用 **core library desugaring**，使 `java.time` 等 Java 8+ API 可用；全量 Media3 后备路径 |
| Android 8.0–8.1 | 26–27 | 后台执行限制、通知渠道 | 播放动作才请求启动前台服务；弱网、失效流及首次启动下的前台服务时序待实测 |
| Android 9 | 28 | 明文流量默认禁止 | 通过 `network_security_config` 显式放行（自建服务常用 http），生产可收紧 |
| Android 10 | 29 | 分区存储 | 暂无文件下载，后续下载模块将使用应用私有目录 |
| Android 11 | 30 | 包可见性 | 无跨应用查询，无需 `<queries>` |
| Android 12 | 31 | 前台服务后台启动受限、动态取色 | 播放只能从可见界面触发；动态取色默认关闭 |
| Android 13 | 33 | 通知运行时权限 | `POST_NOTIFICATIONS` 运行时申请；拒绝后不阻塞使用，播放器内提示「后台通知可能受限」 |
| Android 14 | 34 | 前台服务类型必须声明 | `foregroundServiceType="mediaPlayback"` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 权限 |
| Android 15 | 35 | 强制 edge-to-edge | 使用 `enableEdgeToEdge()` 与透明系统栏，主题中也设置透明状态/导航栏 |

**安装门槛**：`minSdk 24`（Android 7.0）；`targetSdk 35`（Android 15）是行为适配目标，不是最高可安装版本，也不代表已逐版本实机验证。

## 2. 设备形态

- **手机（含 320dp 小屏）**：360dp 以下自动降低一档字号（CompactTypography），列表项使用 `defaultMinSize` 而非固定高度。
- **超大字体（fontScale > 1.3）**：正文与标题均为 sp 自适应，关键行高改用最小高度约束，不裁剪文字。
- **平板 / 折叠屏**：内容区 `widthIn(max = 840.dp)`，避免超宽文案行；`resizeableActivity="true"` 支持分屏与多窗口。
- **横竖屏切换**：Activity 声明 `configChanges`，旋转/分屏不重建，播放状态不丢。
- **ABI**：按 `armeabi-v7a` / `arm64-v8a` / `x86_64` 拆分 APK，并提供 universal 包兜底。

## 3. 语言与区域

- 资源只保留 `zh` / `en`（`resourceConfigurations`），其他语言回退英文，避免部分 ROM 的资源缺失崩溃。
- 数字与日期统一走 `java.text.SimpleDateFormat` + `Locale.getDefault()`，不硬编码格式；阿拉伯语/希伯来语等 RTL 语言由 `supportsRtl` 镜像布局。
- 时区：服务端统一存 UTC，客户端按本地时区展示（`util/Dates.kt`）。

## 4. 弱网与离线

- `NetworkMonitor` 监听连通性变化，断网时「资料库」显示离线横幅而非空态。
- 1.2.5 起，离线或提交失败的播放进度按服务器地址和账号保存。队列总上限 500 条，同一账号同集只保留最近一条，超限淘汰最早入队的记录。当前账号联网或重新登录时尝试补传；成功后只清除已确认且未被更新的快照。旧版无归属的进度队列保留原样，不自动上传。
- HTTP 超时：连接 15s、读写 30s；401 自动用刷新令牌续期并重放一次，失败才提示重新登录。
- 服务端抓取 RSS：跟随最多 10 次跳转、20s 超时、20MB 上限，失败时回退到已缓存的节目数据（离线仍可浏览）。

## 5. 服务端运行环境

- 单静态二进制（`CGO_ENABLED=0`），Linux amd64/arm64 均可；Docker 镜像基于 alpine。
- SQLite（`modernc.org/sqlite`，纯 Go，无 CGO），WAL 模式，单机即可；数据目录可用 `APP_DATA_DIR` 指定。
- 兼容多种 `DATABASE_DSN` 写法（纯路径 / `file:` / 已含 `_pragma`）。
- 健康检查 `GET /healthz` 返回 `database` 状态；数据库不可用时返回 503（便于 LB 摘除）。
- 接口同时提供带 `/auth` 前缀与不加前缀的别名（`/login` 与 `/auth/login`），旧客户端不会因路径调整失效。

## 6. 老数据与老客户端

- 数据库启动时执行幂等迁移，并对历史版本缺失的列做 `ALTER TABLE` 兜底（重复列错误被吞掉，不会阻塞启动）。
- 请求体解析允许缺失的可选字段，拒绝未知字段；非法输入统一返回 4xx 而非 500（有测试覆盖）。
- 分页参数越界自动收敛（`limit` 限制在 1–200，`offset` 负数归零）。
- 邮箱大小写不敏感；时间戳解析兼容 `RFC3339`、`2006-01-02 15:04:05`、纯日期等格式。

## 7. 导入模式与内容来源

- 关闭默认全球目录不影响自行导入 RSS、电台流及已保存的个人音源。
- 批量粘贴每行 URL 或 `名称|URL`，上限 100 条；错误按行提示，失败保留输入。
- 大陆官方入口使用浏览器打开；没有浏览器时显示错误，不抓取隐藏音频接口。
- 空目录配置不会访问外部服务，旧客户端继续收到稳定的空列表响应。
- 音源可达性、国家标签不是授权证明；详见 [内容来源说明](<CONTENT_SOURCES.md>)。

## 8. 已验证 / 未验证

**已验证**
- Go：`go vet` + `go test ./...`（含 CORS 预检、最小字段客户端、非法输入不 5xx、分页越界、GBK/GB18030 编码源、超大 feed）。
- Android：`:app:assembleDebug` + **25 个单元测试**（原有 8 项 + 导入解析/官方入口/直播展示 17 项）；APK 的 `minSdk=24`、`targetSdk=35`、versionCode=4、versionName=1.2.1-debug 已通过 `aapt2 dump badging` 校验。
- C++：构建和 CTest 通过；两后端未设置/空串/空白目录禁用、显式本机目录、RSS/电台导入与用户隔离，共 8 组端到端场景通过。

- Android `lintDebug`：0 errors、9 warnings（含既有明文流量配置、导出播放服务、静态 Context 持有和样式建议；不能视为正式发布安全认证）。

**未验证（需要真机/模拟器）**
- Android 7.0/8.0 老机型的实际运行（无可用设备）。
- 平板/折叠屏的多窗口布局效果。
- 后台播放通知在 MIUI/ColorOS 等定制系统上的保活表现（各厂商白名单策略不同）。

## 9. Android 真机验收清单（1.2.5-compact）

**准备**：安装 [GitHub Releases 的精简测试包](https://github.com/Luca4Don3/podcast/releases)，准备手机可访问的 HTTPS 测试后端、两个测试账号，以及自己有权使用的 RSS、MP3/AAC 和 HLS 测试源。登录页点「服务器地址（可选）」→「测试连接」→「保存」，再注册或登录；登录后入口位于底部「设置」。不要把电脑的 `localhost` 或模拟器专用地址填给真机。

| 检查项 | 操作和通过条件 |
| --- | --- |
| 服务器地址 | 无预设地址时可留空，不发起登录或注册请求。填写测试地址并测试连接，保存后重启确认仍生效；在「设置」清空时恢复预设或未连接状态。实际换到其他服务器时需要重新登录。 |
| RSS | 「RSS 导入」粘贴地址 →「导入并订阅」。节目出现在资料库，打开单集可播放。 |
| 单条与批量导入 | 「电台」→「我的音源/导入」保存一条，再切换批量导入。分别提交有效批次和含无效或重复行的批次；后者提示行号、不提交且保留输入。 |
| 播放与切换 | 试听授权的 MP3/AAC 和 HLS 直播，确认有声音且不显示播客进度；锁屏后测试媒体控件，再切回播客，确认原进度未被直播覆盖。 |
| 账号隔离 | A 收藏一条测试音源，切换到同一后端的 B，列表中看不到 A 的音源；切回 A 后仍可见并可移除。 |
| 进度补传 | 用账号 A 播放单集，断网后在已缓冲范围内拖动进度并暂停。若要测试跨账号，先在断网时退出 A，恢复联网后登录 B，确认不会补传 A 的记录；再登录 A 核对补传。另在两个不同的测试服务器上核对隔离。 |
| 首次播放 | 冷启动后先浏览资料库，再首次播放点播；另一次冷启动后首次播放电台。检查首播及锁屏暂停、续播。 |
| 官方入口 | 「电台」→「大陆官方入口」逐一打开云听和央广网。预期在系统浏览器打开对应官网，不新增个人音源，也不在 App 内自动播放。 |

失败时记录机型、Android 和 App 版本、网络及操作步骤。服务器端检测连通不代表手机能播放。不要分享账号、令牌或带签名的 URL。以上为待实测项目，不是设备测试结果。
