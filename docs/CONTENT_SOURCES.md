# 内容来源与导入边界

## 产品定位

App 提供个人音源导入、管理与播放功能，不运营开放上传、转播或全球电台推荐平台。
用户仅应导入自己有权使用的 RSS / HTTP(S) 音源。音源可连接、免费收听或服务器位于中国大陆，都不是版权许可的证明。

默认关闭外部播客、电台目录，不预置直播流，不自动导入或播放任何内容，不删除用户原有音源。
当前“部分中国大陆内容”以**官方内容入口**提供：点击后在系统浏览器访问内容方，不宣称已取得第三方集成、再分发或商业授权。
如果需要在 App 内直接播放某个内置频道，应先取得可核实的接入许可；未确认许可时保持外链形式。

## 扩展可播放的内置大陆内容前

1. 核对发布主体、官方页面、内容权利人及授权链，不依据聚合网站标签或 IP 地区判断合法性。
2. 记录许可文件或公开许可证链接，确认允许第三方 App 接入、地域（中国大陆）、用途（含是否商业）、有效期和署名要求。
3. 使用内容方明确提供的 RSS、播放接口或稳定直链；不绕过登录、付费、签名、DRM 或地域限制。
4. 不复制音频和台标到自有存储，除非相应许可明确允许；内容撤回、许可到期时停止推荐。
5. 对外运营前单独核实隐私、版权、备案及适用业务资质；“只做播放器”不构成合规保证。

## 外部目录配置

两个后端均保留兼容接口供已有客户端使用，但默认禁用：

环境变量（空值为关闭，不自动回退）：

```dotenv
ITUNES_SEARCH_URL=
RADIO_BROWSER_URL=
```

管理员仅在核实内容许可、地区和接口协议后，才应明确配置目录端点。地址可配置不意味着任意目录协议均兼容，也不构成自动授权审核。
旧部署若已配置目录 URL，应显式清空相应变量；本次修改不读取或改写生产密钥文件、不重启现有服务。
